# Product API

A REST API built with Spring Boot for managing products.

## Features

- CRUD operations
- Spring Data JPA
- MySQL
- DTO pattern
- Bean Validation
- Global Exception Handling
- Pagination
- Category filtering
- Swagger/OpenAPI
- Unit tests with JUnit & Mockito

## Tech Stack

- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Lombok
- Swagger/OpenAPI
- JUnit 5
- Mockito

## Endpoints

GET /products
GET /products/{id}
POST /products
PUT /products/{id}
DELETE /products/{id}

GET /products?page=0&size=5
GET /products?category=Electronics
